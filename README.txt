SEOUL FIREWORKS FINAL

실행 방법
1. 폴더를 VS Code에서 엽니다.
2. index.html을 Live Server로 실행합니다.

수정 사항
- desktop / mobile 배경 이미지를 분리했습니다.
- mobile은 1080x1920 세로 전용 이미지입니다.
- 원본 이미지에 들어 있던 글자와 HTML 글자가 겹치지 않도록 좌측/상단에 전용 scrim(어두운 안전영역)을 만들었습니다.
- 데스크톱에서는 폭죽 중심을 오른쪽 하늘로 옮겨 인트로 텍스트 영역을 침범하지 않게 했습니다.
- 모바일에서는 제목을 상단 안전영역에 두고, 도시 스카이라인은 아래쪽에 유지합니다.
- safe-area, 390px 이하 소형 화면, 태블릿 구간을 대응했습니다.
